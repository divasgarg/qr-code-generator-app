# QR Code Generator

Enter text or a URL to preview a 256 × 256 QR code. Select **Download QR Code** to save it as `qr-code.png`. The app generates the image in your browser using React and `qrcode.react`.

## Run locally

```sh
npm install
npm start
```

Open http://localhost:3000 in your browser. Run `npm run build` to create a production build.
